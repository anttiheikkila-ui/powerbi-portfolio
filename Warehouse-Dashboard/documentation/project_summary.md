# Project Summary

## Objective

The goal of this project is to demonstrate how Power BI can be used to analyze warehouse inventory and support data-driven supply chain decisions.

## Business Questions

- How healthy is the inventory?
- Which products are below reorder point?
- Which products are below safety stock?
- What is the inventory turnover rate?
- Which product categories represent the highest inventory value?

## Technologies

- Power BI
- DAX
- Power Query
- Excel
