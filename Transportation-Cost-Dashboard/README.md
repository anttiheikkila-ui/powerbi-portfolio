# Transportation Cost Dashboard

Power BI dashboard focused on transportation cost analysis, carrier performance and route optimization.

The solution demonstrates how Power BI can be used to monitor logistics KPIs, analyze freight costs and support data-driven transportation decisions using dimensional modeling and DAX.

## Dashboard Pages

### Executive Overview

![Executive Overview](images/Executive%20Overview.png)

Provides a high-level summary of transportation performance through key business KPIs.

---

### Carrier Performance

![Carrier Performance](images/Carrier%20Performance.png)

Compares logistics providers based on transportation cost, transit time and on-time delivery performance.

---

### Route Overview

![Route Overview](images/Route%20Overview.png)

Analyzes transportation routes, destination countries and freight costs to identify optimization opportunities.

---

### Data Model

![Data Model](images/Data%20Model.png)

The solution is built using a dimensional star schema consisting of one fact table and multiple dimension tables.
