# SAP Logistics Control Tower

An end-to-end Supply Chain Analytics solution built with **Python** and **Power BI**, inspired by real-world SAP S/4HANA logistics processes.

The project demonstrates how operational data can be generated, validated and transformed into interactive business intelligence dashboards for procurement, inventory, transportation and exception management.

---

## Project Overview

The solution consists of a Python-based data generator and a Power BI reporting solution.

Python is used to generate realistic ERP-style mock data, apply business rules and export validated datasets for Power BI analysis.

Power BI is used to build interactive dashboards that provide visibility into the entire logistics process—from purchasing to inventory, deliveries and transportation.

---

## Project Architecture

```text
Python

└── Export Excel & CSV
        │
        ▼
Power BI
│
```
